# angular-boilerplate — open risks

What is not yet proven or not yet decided. The full write-up of every risk,
including the accepted and resolved ones, is
`specs/epics/angular-boilerplate/risks-and-open-questions.md`; this page lists
only what is still live, so it should be short.

| ID | Risk | State | What closes it |
|---|---|---|---|
| NG-A | `baseline-v1` is not yet proven live | OPEN | One console bootstrap from `baseline-v1` |

Accepted, and worth knowing before you change them: NG-B (Angular 22, not the
template's 15), NG-C (standalone, not NgModule), NG-D (the Worker's 404 rule
for file paths), NG-E (the template's component-style budget warns on its
own welcome page), NG-G (zone.js kept).
